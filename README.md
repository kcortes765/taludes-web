# TALUDES

[Abrir aplicación](https://kcortes765.github.io/taludes-web/)

Análisis preliminar 2D de estabilidad de taludes mediante Fellenius y Bishop simplificado. Abrir `index.html` para usar localmente; no requiere instalación.

Suelo homogéneo y falla circular, con tratamiento simplificado del agua y grietas de tracción. La búsqueda explora una grilla finita y no garantiza el mínimo global. Monte Carlo estima la falla de una superficie fija, con variables independientes; no representa la falla global del talud. Los umbrales de FS son orientativos.
